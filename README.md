# 🌍 Go Trip — Full Stack Travel Website

A full-stack travel website designed to help users explore destinations and manage their travel-related activities through a simple and user-friendly interface.

## 🚀 Tech Stack

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Java
- Spring Boot
- REST APIs

**Database**
- MySQL

**Tools**
- IntelliJ IDEA
- Visual Studio Code
- Git & GitHub
- Postman

## ✨ Project Highlights

- Responsive travel website interface
- Destination and travel information pages
- User profile and booking-related pages
- Ticket and booking interface
- Spring Boot backend integration
- MySQL database connectivity

*Note: Features listed above should reflect the functionality currently implemented in the project.*

## ⚙️ Run Locally

### Frontend
1. Open the `frontend` folder in Visual Studio Code.
2. Run `index.html` using Live Server.

### Backend
1. Open the `backend` folder in IntelliJ IDEA.
2. Configure the MySQL database and application properties.
3. Run the Spring Boot application.
4. The backend typically runs at `http://localhost:8080`.

### Database
- Install and start MySQL.
- Create the required database.
- Configure database credentials using local configuration or environment variables.
